## Manuscripts — v28, the edit drawer, genres and UK ages (22 Oct; ref = design-refs/manuscripts-v28/manuscripts-v28.html; report reports/manuscripts-v28/REPORT.md; on branch `manuscripts-v28`, NOT merged; AMENDS v27 below)
- **Edit details is ALWAYS the slide-in drawer (`v28/MsEditDrawer.tsx`, the shared `HalfDrawer`, probe `ms-edit`), never a centred modal.** `Msv21EditDetails` is deleted. Five sections in order: The book · Logline · Elevator pitch · Synopsis · Series. Every entry (the header, the book view, the guide's steps) opens it.
- **No Setting in the UI.** The field stays in the type and on stored records; nothing renders it (v21's `bookFacts` still names it and has no caller). **Series is a switch:** on writes `"Part of a series"` unless a value is already stored; off OMITS the key (`deleteField()`), never `""`. The book view always shows a Series row ("Standalone" when unset).
- **The word-count hint is silent unless the count is under 75% or over 125% of the genre's range** (`lib/manuscriptV28.wordCountHint`).
- **Genres: one main genre plus up to three more (`MAX_ALSO`), promoted with ↑ Main, never by pick order.** The picker is `v28/GenreField.tsx` with predictive `searchGenres` (exact 100 · prefix 80 · word prefix 60 · alias 50 · substring 30, +5 for a main genre, then relatedness to what is picked). Stored as LABELS, as before. An own genre is registered through `addPersonalGenre` on Save, never on pick.
  - **⚠️ 67 SUB-GENRES, EACH WITH A `parent` THAT IS A MAIN GENRE, AND `genreAndAncestors` MAKES EVERY MATCHER COUNT A SUB-GENRE AS ITS PARENT** — `genreMatch.bookGenreHit` (via `bookKeys`), `isGenreMatch`, and the Discover score in `communityMatch`. Agents still pick main genres only (`GenrePicker`, onboarding's `GENRE_LIST` filter out `parent`). Several aliases MOVED onto sub-genres ("psychological thriller", "noir", "whodunnit", "cosy mystery", "gothic", "epic fantasy", "romcom"…).
- **UK age labels, sentence case, Adult first and the default:** Adult · Young adult · Middle grade, then Young fiction · Picture book · New adult under Other (`lib/ageCategories`). **Every reader goes through `normaliseAgeCategory`**, so a stored "Early Reader", "Middle Grade" or "Young Adult" displays and matches as the new label. Nothing was migrated.
- **The page foot is a bar and two tiles (`v28/MsFoot.tsx`) that fill to the content bottom less 28px** (`.ms28-fill`, measured 28.0 at 1512 and 1280). v27's coming-soon strip is deleted. The tiles' art is a TODO(illustration).
- **⚠️ ONE WAY A DROP-DOWN CLOSES: `shell/useDismissable`** — an outside press (capture), Tab away (`focusin`), Escape as a layer on the escape stack ABOVE the drawer (so only the menu closes), and a pick. The guide's popover takes the same behaviour through an OPT-IN `closeOnFocusOut` on `PageChecklist`, which only Manuscripts passes; the Contact list and Query Centre are unchanged.
- **⚠️ A VISIBILITY PROBE MAY NOT READ `offsetParent`** — it is null for a `position: fixed` element, so G1's first version reported the fixed guide popover closed while it was open, and a mutation stayed green. Read the rendered box.
- **v28.1 (22 Oct; report reports/manuscripts-v28-1/REPORT.md; branch `manuscripts-v28-1`, NOT merged):** the header reads **Edit** and **View summary**, the book view's footer reads **Edit**, "Read it all" is gone (the details card still opens the book), and the logline ends with a rust ” bound to its last word (`v28/QuotedLine`). ⚠️ **No break can fall before a closing quote mark anyway** (Unicode LB19, plus `text-wrap: pretty`), so removing the no-wrap span cannot redden MSV281-A3; it was proved red with a breakable mark instead. Locks: `tests/e2e/manuscriptsV281.measure.ts`.
- **Locks:** `tests/e2e/manuscriptsV28.measure.ts` A1, A2, B1, B2, C1, D1, D2, E1, E2, F1, G1 at 1512 and 1280 (B1, D2 and E2 write the ms21-filled book and put it back through `tests/e2e/ms28Fixture.mjs`); unit halves in `lib/manuscriptV28.test.ts`, `lib/ageCategories.test.ts`, `v28/msv28Smoke.test.tsx`.
