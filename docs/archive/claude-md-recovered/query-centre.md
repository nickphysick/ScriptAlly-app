## Query Centre — v152 (4 Nov; ref = design-refs/query-centre-v152/query-centre-v152.html + query-states-v2.html + screens 01–27; report reports/qc-v152/REPORT.md; branch `query-centre-v152`, NOT merged; desktop only — the phone keeps its own card)
- **Six query states, one function: `lib/queryState.ts`** — Offers · Materials requested · Nudge due · With the agent · Gone quiet · Closed. The desktop list stamps each row once where it builds them (`stampRows` in `Queries.tsx`: `qs`, `quietDays`, `replyMs`); the groups, tags, quick filters, next-action groups and the card read the stamp. **Every other reader keeps the old four-set rule** (`whereItStands`, `buildQcRows`' `court`): the report lists them.
  - **⚠️ THE NUDGE IS `lastNudgeSentDate`, FALLING BACK TO `nudgeDate`** (Nick's ruling). `nudgeDate` is the PLANNED nudge (`logDefaults` writes one at log time), so a future date, or one before the latest send, is no nudge. Nudged → With the agent until the nudge plus the quiet window, then Gone quiet. Not nudged → Nudge due from the reply date, Gone quiet once the window has passed since it. "No reply means no" → Gone quiet on the reply date. Undated → the 84-day rule.
  - **The quiet window is a setting** (2 · 3 · 4 · 6 · 8 weeks, default 4): the gear in the navy banner (`QcQuietSetting`), stored at `todoPrefs.queries.quietWeeks` by dotted path.
  - **Your move = Offers + Materials requested + Nudge due.** Gone quiet is its own group; its header is stone fading to white (`QUIET_BAND_HEAD`), its card band `QUIET_BAND`.
- **⚠️ PARTIAL AND FULL WAIT THE HOUSE 12 AND 12 WEEKS** (`STAGE_RESPONSE_WINDOWS`), in the save path (`sentDefaults`, the sent journey's "usual") and on the page (`expectedFor`); only the query stage reads the agent's `responseTimeWeeks`. The partial's save used 8 until v152.
- **The card is `QcQueryCard149` (one card, Nick's ruling); on the desktop its reading view is `QcCard152`** — the landing card's frame, 540 wide (504 ≤1400), a FIXED height `min(700px, 100vh − 56px)`, centred by `top`, 40px from the right (28 ≤1400), leaning 1.6° by the `rotate` property (`none` in any editing view, which also stops the panel being a containing block). It sits at z 68, over the shell's bar (67 while a panel is open), because centred its band reaches the bar's row. The phone passes `layout="phone"` and is untouched.
  - **The Tracking tab is a chat thread** (`lib/qcThread152`): the agent's steps left (requests, an offer, a pass, a holding reply), yours right; a 34px disc in the status's cap colour (none for Query sent and a nudge); the waits between steps with tips in facts; "N days · today"; how it ends by state. **"Their usual" only when the agent states a reply time.**
  - **A step's chips are what was recorded ON it** (`materials` on both activity stores, a list of maps; dev rules deployed). Older steps carry none and show none, except Query sent, which shows the query's own record.
  - **The reply box** names the next move per state; its button never writes.
