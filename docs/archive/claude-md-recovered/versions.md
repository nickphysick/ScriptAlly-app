## Versions v1 — /manuscripts/versions (22 Oct; ref = design-refs/versions-v1/versions-v1.html; report reports/versions-v1/REPORT.md; on branch `versions-v1`, NOT merged)
- **The Versions page is `components/versions/VersionsV1Page.tsx`, every figure `lib/versionsPage.ts`.** It replaces v27 Part E's interim page (`manuscripts/v27/VersionsPage`, still in the tree, mounted nowhere). Header (the ms27 hero, "of {title}") with the active-version card → the warning banner → the list → the comparison (thin banner, cards, league).
- **⚠️ A QUERY REACHES A BOOK VERSION ONLY THROUGH `packageReplies.creditedSlot(q, "version", packages)`** — the version the credited EDITION of the package that went out stated. A query with no package, or whose edition stated none, reaches no version and is counted only in the banner and the league's footer link; never folded into a known version. (`manuscriptSummary.queryVersionId` reads the package's CURRENT version; `queryVersions.openingRead` still goes through the sample and is stale.)
- **⚠️ THE BANNER IS NOT `unrecordedVersion`** — that counts only packaged sends; the banner counts every live query reaching no version (37 against 7 on the harness's seed-ms-1).
- **⚠️ PRO, AND FOUNDING MEMBERS IN FULL: `entitlements.versionsUnlocked` = `VERSIONS_FOUNDING_ACCESS || plan === Pro`, the constant ON** (Nick's ruling; no founding flag exists, everyone is founding in the beta). Nobody is locked today; the Free state shows on DEV builds through `sessionStorage["sa.dev.versionsFree"] = "1"` (behind `import.meta.env.MODE`).
- **The active version is the active package's version** (`resolveActivePackage`). Change → `setActivePackage` with the newest live package stating it; Undo puts back the previous `activePackageId` exactly. No package states it → the package form with that version chosen.
- **⚠️ SUBMISSION PACKAGES READS `?new=1&version={id}`** (23 Oct): it waits for the manuscript, then opens its package form with that version chosen; a version the book doesn't hold opens it empty. Every Versions "Add to a package" and a no-package Change go there (VER1-E1).
- **Book versions have no retired state and no delete**; the row menu is Edit · Add to a package. New/edit is the HalfDrawer form, writing through `appendBookVersion` / `renameBookVersion` (edit = name and note only).
- **Positive is navy; rust only on eyebrows, the blush strip and the discs** (the mock's rust "Landing best" is navy).
- **Locks:** `tests/e2e/versionsV1.measure.ts` A1–D3 (expected values from `tests/e2e/ver1Fixture.mjs`, Firestore read directly); B2 writes and Undo restores the manuscript byte-for-byte. ⚠️ A sidebar row with no icon falls back to its SECTION's icon, so "the row has an svg" proves nothing.

## Versions v2 — the Versions page (23 Oct; ref = design-refs/versions-v2/versions-v2.html; report reports/versions-v2.md; branch `versions-v2`, NOT merged)
- **A query stores its book version (`Query.bookVersionId`), and `resolveQueryVersion` (lib/versionsV2) is the one reader:** the query's own, then its package's (credited edition, package, sample), then Original by date, else unrecorded. `VERSION_NOT_SURE` is "Not sure yet" said on purpose and stays unrecorded. `db.addQuery` stamps every logged query (package's version, else in use) except imports.
- **Original is auto-created at the first save and is the root; every version has one parent; numbers are never reused (`bookVersionSeq`); `inUseBookVersionId` is the one in use.** Every write is lib/bookVersions + one `db.writeVersionChange` batch, and every Undo is `versionSnapshot` (absent stays absent: `null` deletes the key).
- **Rates, ranking and "Leading" only from 5 sent (`MIN_SENT_FOR_RATE`); "asked for more" is Analytics' `reachedRequest` (history), never the current status.**
- **⚠️ versionsV2.css IS GENERATED** (`scripts/versions-v2/extract-css.mjs` then `gen-css.mjs`); hand edits go in versionsV2.app.css. Three traps the generator handles: the CSSOM turns a `font:` shorthand holding a `var()` into empty longhands (bodies come from the ref's source text), `@container` rules, and the ref's own `--sp-type`/`--sp-serif` redefinitions, which cycle with the app's tokens and blank every face while every gate stays green.
- **Prod rules for the three new fields are Nick's and must precede any prod deploy of this page.**
