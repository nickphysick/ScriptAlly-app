## Comparable titles v26 — the add-and-edit comp drawer, and the first-comp explainer (12 Oct; refs = design-refs/materials/comps-v26-add.html + design-refs/comps-v26/*.png; report reports/comps-v26/REPORT.md; on branch `comps-v26`, cut from `comps-v25`, NOT merged)
- **One form for add and edit** (`manuscripts/CompForm.tsx`), inside v25's comp drawer. The drawer has a head, a scrolling body and a pinned foot and all three read the form, so the state is a hook the drawer calls once (`useCompForm`) and the body and the foot are two components (`CompFormBody`, `CompFormFoot`). The hook starts again whenever its `resetKey` changes (set during render, so no frame shows the last comp's fields).
- **The drawer's title is its only heading** ("Add your first comp" / "Add a comp" / "Edit {title}"). The section heads and the explainer's heading are `<p>`s, deliberately.
- **Type comes first and the labels follow it** (`FIELD_COPY`): Book → Author / Publisher; Film → Director / Studio or distributor; TV → Creator / Network or channel; Other → Creator / Publisher or platform. Changing type keeps what is typed. The fields are still `author`, `publisher`, `year` and `media`.
- **Only the title is required. The ready note never blocks a save**: its state is `readyState()`, which is `ready()` (lib/compUsage) plus "idle" before a title is typed. Save reads the title and nothing else (unit-locked).
- **Tags are `matchAxis`, unchanged**: joined with " · ", at most six, no duplicate ignoring case (`withTag`).
- **The preview is the library row's own cells**: `CompCell` and `NextCell` are exported from `comps25/CompsLibrary.tsx` and the list's row draws the same two. A new comp previews as `draftRow()` (on the shelf, in no letter); an edited one keeps its own row.
- **A plain Add closes the drawer** (v25 switched to the comp's view). "Add and add another" keeps it open on a cleared form: type Book, explainer folded, body at the top, focus in Title. The toast is "Added {title} to your library." with Undo.
- **The explainer** (`comps25/CompExplainer.tsx`) is add-only: open when the manuscript has no comps, one link otherwise, never stored. Its drawing is the dashboard's `DASH_ART.mentorLooking`. ⚠️ Its sheet is bundled before `compsV25.css`, whose font reset is 0-1-0, so every rule in it is `.cf-body …`.
- **The empty-state exhibit lost its query line, its reorder hint and its drag handles.** It still draws v2's card with the retired "In query letter" switch; that is flagged, not fixed.
- **Harness:** `tests/e2e/compsV26.measure.ts` (AD1–AD9) and `adMutations.sh`, on v25's fixture and `cv25Lib`. ⚠️ The head's disc also carries `data-media`: scope the type control's buttons with `[data-cf="type"]`.

## Comparable titles v25 — comps logged against query letters (12 Oct; refs = design-refs/materials/comps-v25.html + design-refs/comps-v25/*.png; report reports/comps-v25/REPORT.md; on branch `comps-v25`, NOT merged; SUPERSEDES comps v2 below for the page's shape)
- **Comps belong to query letters.** A comp has a stable `id` (`cmp_` + random, given on its first write, never reused). A Query Letter version records the comps it mentions in `compIds`: **absent means "not recorded", `[]` means "recorded: mentions none".** Every query is traced to its letter (`letterOf`), so a comp's queries are the queries whose letter names it. All of it is derived in `lib/compUsage.ts`; nothing is stored beyond those two fields.
- **`letterOf` resolves in this order:** the query's recorded `sentVersions` (the ids that are Query Letter versions; more than one is ambiguous and takes the first), else the package EDITION that went (`sentPackageEdition`), else the package's letter now, else none. A query with no letter is never logged.
- **A sent letter whose comps are recorded is FIXED; a change is a new version. A letter sent with nothing recorded can be filled in once.** Client-enforced twice: the picker offers no checkbox, and `updateVersion` refuses a `compIds` write to a fixed letter (`{ restoring: true }` is the Undo of the one save). **The rules cannot enforce it**: they would need to query the user's queries.
- **`CompTitle.inQuery` is RETIRED.** Nothing outside `types.ts` reads or writes it (`compsInQueryRetired.test.ts`); `normalizeComp` no longer names it, so a stored value is dropped on the comp's next write. `queryLine` takes the letter's comps from its caller (`compsInLetter`).
- **The current letter is the newest Query Letter version that is not retired** (`currentLetter`, the one the query drawer marks CURRENT). The Manuscripts page's comps door reads its `compIds`. ⚠️ That page's "You're using {letter}" still comes from `letterInUse` (the most recently sent query's package letter), so the two can name different letters.
- **"Asked for more" is the analytics `reached` derivation** (`buildRows(...).reachedRequest`), never a status list of this page's own.
- **The page:** `PanelHeader kind="title"` mounted directly with `data-own-header` (the route is in `OWN_HEADER_ROUTES`, and a TITLE page in `headerV3`), the "At a glance" strip, the how-it-works band, then the library (a heading and the list, both the list's width, broken out to the sheet by `--hsheet-w`). A row opens `CompDrawer` (HalfDrawer); "Log comps in a letter" opens `CompLetterPicker` (portalled, `ESC_LEVEL.pageModal`). The Scout is a `FloatingTab` and a `HalfDrawer`, coming soon, and nothing reaches `suggestComps`.
- **One filter at a time; the column headings are the sort** (first click sorts, second reverses, third returns to the writer's own order, which is the stored array order). **Drag-to-reorder is retired from this page.** Grouping is None by default.
- **⚠️ Under "Query letter" grouping a comp two letters name is in both bands**, so those bands sum to more than the list. Every other grouping partitions it.
- **Shared parts built here, used by this page only so far:** `shell/strip/GlanceStrip` (the v137 strip's values under a `gst-` prefix; `QcStrip` was not rewired), `shell/useFullScreenList` (the URL `?full=1` is the state, `localStorage` remembers it, Escape leaves it last at `ESC_LEVEL.pageMode`) and `shell/sidebarForce` (a page HOLDS the sidebar collapsed and releases it; it never writes the writer's own choice). The Contact list can adopt the last two.
- **⚠️ The drawer, the picker and the Scout are portalled**: their rules hang off `.cv-layer` and read literals and `:root` tokens only; the comp form inside the drawer is wrapped in `.cpv-scope`, which carries the form's `--cpv-*` tokens.
- **⚠️ The strip cells reserve their loaded height** (`.cv-group > .gst .gst-foot` 62px, a second line under 1040px of strip), or the page jumps when the data lands (L1 was red without it).
- **⚠️ Two probes collided with the page's own containers**: `data-cv="bar"` (the list's ink bar and the strip's bars) and `data-cv="group"` (the page group and a band group). The strip's are `rate-bar`, the band's is `grp`.
- **Harness:** `tests/e2e/compsV25.measure.ts` (B1–L1 on the rendered page), `cv25Lib.ts`, `seedCompsV25.mjs` (`--dump`, `--restore`, `--empty`), `cv25Mutations.sh` (seven in-page mutations, six source mutations with a rebuild each, restored from copies). ⚠️ **Do not edit `src/` while it runs**: the bundle guard refuses a stale bundle, and it is right. Retired: `tests/e2e/RETIRED-comps-v25.md`.

## Comparable titles v2 — the page's own group, the Scout coming soon (27 Sep; ref = design-refs/materials/comps-v2.html; report reports/comps-v2/REPORT.md)
- **`/manuscripts/comps` renders its OWN group like the Contact list: `WorkspacePageGrid masthead={null}`, the shared `PageHeader variant="full"` as row 1 across both tracks, the main column and the rail as row 2 at the rule + 24.** OPTED_OUT is 4 (unit census and `tests/e2e/optedOut.ts`); FULL_PAGES has three. No art until Nick supplies it (`WITHOUT_ART`, D6). The header is wrapped in `.cpv-head` because the page's sheet may not name `.ph*` (S7).
- **⚠️ THE RAIL IS `PageRail` (`components/containers/`), THE ONE SHARED SIDE PANEL.** Sticky at 16px inside the scroller, 340 wide, a `--mat-tray` head, and a `max-height` equal to the height it has WHEN STUCK — from the scroller's measured top through `railHeight`, never `100vh`. `ContactRail` (a HEIGHT from its current top) and `QcRail` are migration candidates, not migrated.
- **⚠️ THE SCOUT IS "COMING SOON" AND THE PAGE CANNOT REACH IT.** `ScoutPanel` moved verbatim to `ScoutPanel.tsx` and is mounted nowhere; nothing the page mounts imports `lib/suggestComps`; `SCOUT_LIVE` is untouched. Locked at unit (C5) and rendered (no request to `suggestComps`, no enabled control in the rail).
- **⚠️ NO COMP WRITE FAILS SILENTLY.** Every write is the page's `commit()` → `lib/compsWrite.runWrite` (never rejects): an optimistic list, then on a refusal the list comes back and "Couldn't save that change. Check your connection and try again." `updateManuscript` is called from exactly one place. **Firestore's latency compensation already reverts a refused write on its own** — what was missing was catching the rejection and saying so. C9 proves it with a REAL refusal (a 1.15MB note; the backend refuses the document), no seam in the product.
- **New `:root` tokens (index.css, mirrored in designTokens.ts, agreement locked):** `--o-scout` (#467a76, the third object colour; it was only `--msv12-scout`) and the materials surfaces `--mat-parch-2/3`, `--mat-tray`, `--mat-soft`, which the packages page reads too. The page's `--cpv-*` are aliases only.
- **⚠️ A MOCK'S LINE-HEIGHTS ARE MEASURED, NOT GUESSED.** A part-by-part height probe (app vs mock, same ruler) found seven drifts the frame locks could not see — headings given 1.3 where the mock inherits 1.45, invented 1.2/1.3 on chips and spines, a `margin` shorthand wiping a 6px right margin, and inputs at 39px because Tailwind's preflight gives form controls `font: inherit`. **State `line-height: normal` on inputs that must match a plain-HTML mock.**
- **Harness:** `tests/e2e/compsMat.measure.ts` (S1–S7, C1–C9) with `seedCompsFixture.mjs` (two manuscripts titled as the mock's, `--dump <id>` prints what was STORED, `--restore` in `afterAll`). The v3 suites are retired in `tests/e2e/RETIRED-comps-v2.md`; eleven masthead-era censuses still list the page as `ct-wpg` — a deferred census pass, named there.
