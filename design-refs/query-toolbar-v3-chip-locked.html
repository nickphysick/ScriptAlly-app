Pills. Each control states its own name and its current value: mono label in `--label`, Playfair value in ink, burgundy chevron, 99px radius, 9/16 padding — the same shape family as the search and the view switch, so the row reads as one set of instruments. 1 is the straightforward version; 2 stacks the label above the value for a taller, calmer pill; 3 makes the label a parchment chip inside the pill; 4 joins all three plus the count into one white rail with hairline dividers. 3 is locked.

Defaults follow the view. Grid → Sort Last activity, Group None. List → Sort Date sent, Group None. Board → Group is fixed at Status and the pill reads `Group Status` disabled. Calendar → Sort Date sent. Switching view resets the pills to that view's defaults unless the writer has changed them in this session, in which case their choice is kept and the pill shows it.

Skeleton. Same geometry as the real page — nothing moves when data arrives. The masthead, tiles, well and toolbar render as solid chrome immediately (they need no data); only the counts, the search's placeholder and the cards are bones. Six card skeletons at the grid's own dimensions, band block in `#f4efe8`, a 40px circle, two lines for the name and agency, a rule, two lines for the fact — sheen sweeping left to right on a 1.5s loop. No spinner anywhere.

Entrance. Everything rises 10px and fades in on `cubic-bezier(.2,.8,.2,1)`: masthead at 0, tiles staggered 40ms apart, the well at 100ms, then the cards staggered 30ms apart from 180ms. Total 520ms, and the stagger stops after the first row — cards below the fold appear without delay. Skeleton → content is a 200ms crossfade in place, not a re-entrance. `prefers-reduced-motion`: opacity only, no translate, no stagger.
