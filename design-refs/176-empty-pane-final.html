No chassis at all. No card, no sage top edge, no border — the pane's whole job when nothing is selected is to be quietly absent, and a bordered empty box asserts more presence than emptiness deserves. The moment a query is selected the full chassis returns, which also makes selection feel like something arriving rather than something swapping.

The illustration sits in layout flow, in its own row, with the caption in a second row beneath — never absolutely positioned, per the standing law that no positioned element shares space with text. It is an ArtSlot, so the placeholder ships now and the watercolour drops into the same box later with no layout change; the caption's position is fixed by the box, not by the artwork's height.

Caption in Playfair, ink2, one line. No sub-line, no keyboard hint, no counters — the list beside it already shows everything there is to know, and this surface only needs to say why the right-hand side is blank.

⚠️ Two states this must not be confused with. No queries at all (a new account) needs a different line and a way to log the first one — the list beside this one is empty then, so the pane is the only thing on screen. And a search that matched nothing belongs to the list, not the pane. Both stay separate; only "loaded, nothing selected" gets this treatment.
