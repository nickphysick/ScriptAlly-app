Sorting. Four columns sort, three don't. Status (ladder order), Agent (surname A–Z), Sent (date), Where it stands (by the expected-reply date, nulls last) are clickable: hover shows a faint caret, click sorts ascending, click again flips, and the caret turns burgundy. What went, Since then and Actions are not sortable — they're rendered pale with no caret and no pointer. Only one column is sorted at a time, and it is the same state the Sort menu drives, so the menu's label follows a header click and vice versa.

Alignment. Header and rows must be one grid, not two — the same `grid-template-columns` string, the same horizontal padding, rendered by the same component with the header as its first child. Each header cell inherits its column's justification (left for the six, right for Actions), so a header can never drift from its column. Tick "show column guides" above to see the header cell and row cell boundaries drawn together.

My pick: 1, mono caps. A column header is a label for a machine-readable column, not a piece of writing — and the app already has a voice for that: JetBrains Mono, uppercase, letterspaced, which is what every caption, tag and unit in ScriptAlly uses. It sits below the row content in the hierarchy, which is where a header belongs when every row carries Playfair names; the sorted column simply turns ink. The Playfair header I asked for earlier competes with the agent names directly beneath it — that's the inconsistency you're seeing, and it's a real one.

4 is the interesting alternative: each header sits over its own hairline, and the sorted column's rule turns burgundy, so sort state reads across a wide table without a caret. 3 (Playfair small caps) keeps the serif but demotes it properly with letterspacing and uppercase — the compromise if you want Playfair to stay. 2 is the current one with the sizes evened out. 5 wraps only the sorted header in a chip, which is clear but fussy at seven columns. 6 drops the header row entirely for a summary strip — lovely for a short list, wrong once you're sorting.
