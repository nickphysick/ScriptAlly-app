A thread, read top to bottom. Oldest first, newest at the foot, composer docked beneath — the phone-messaging arrangement, and it suits notes on a query because the thread is a chronology of one relationship. On open, the scroller is pinned to the bottom so the newest note is what you see.

Four things this arrangement needs to get right.
  • The pinned note sits above the scroller, not inside it. Chat order would otherwise bury the one note you always want — usually how to reach them, or what to check before nudging. It holds its place while the thread scrolls, and unpins from its own control.
  • Day separators are sticky, so the date of whatever you are reading stays visible as you scroll a long thread.
  • The composer grows with the text to a few lines then scrolls internally, so a long note never pushes the thread off-screen. ⌘+Enter saves, Esc clears, and Save is inert until there is something to save.
  • A new note lands in pink and settles to neutral. Momentary, so you can see what you just added without the thread carrying a permanent second colour.

⚠️ This card scrolls internally, which is the deliberate exception to the page's no-inner-scroll rule — the same exception the to-do list already makes. It needs the full min-height:0 flex chain from card to scroller, and the dock must be flex:0 0 auto or it collapses as the thread grows. Both are the exact faults that took a browser pass to find on the to-do board.
