The toolbar now shares the page grid
  • The query verbs start where the reading pane starts. The bar uses the same two-column grid as the content beneath it — 320px, then the remainder — so Record response aligns with the pairing card's left edge and Delete with its right. Previously the verbs began wherever the count and the icons happened to end, which is why the bar looked unrelated to the pane it controls.
  • Split by consequence, not by frequency. Left: Record response and Nudge — the two things that move the query forward. Right: Mark closed, Export and Delete — the things that end it or take it out of the app. The gap between them is the meaningful boundary, so it does not need a divider to say so.
  • Delete sits at the far right, furthest from the primary, which is the cheapest safety measure available: the destructive verb is the one your hand travels furthest to reach.
  • The count stays in the left column, above the list it counts — so each column's header describes the column beneath it.

⚠️ The grid must be the same one, not a matching pair of numbers. If the columns are ever retuned — a wider list, a different ratio — a duplicated 320px in the toolbar will silently drift out of alignment with the content.
