The six, in order of how much they were costing

Two changes from 101: the agent header is a contained cream plate again (as in 93), so it belongs to the same family as the two cards beneath it; and the list runs flush — no radius, no inset — so it reads as the left half of the interface rather than a panel resting on it. Everything else is unchanged.

  1. The list is furniture again, not a card. It had gone back to a rounded, bordered, inset panel floating on the page — which is what produced the fade, the ragged rows and the double frame around a column that already has a hairline. Flush ground tint, no radius, no border, one seam.
  2. The gradient fade is gone. A fade says "there is more below" — but the list has a foot with Showing 24 of 24, so the fade was contradicting the count sitting right beneath it. Scrolling is signalled by the scrollbar and the foot, not by dissolving the last row.
  3. The masthead is a flat band, flush with the split. It had reverted to the inset plate: 770px wide inside a 1010px body, indented 120px each side, with a rule that stopped short of the columns. Now the rule spans the working width and the title aligns with the list beneath it.
  4. The agent keeps its initials. The avatar circle had degraded to bare text, so the hero lost the one element tying it to the row you clicked. Same 52px disc, same pink, same Playfair.
  5. Rows sit on a three-column grid — 32px avatar · name and agency · status and date — with the date on a fixed 56px right column so every date aligns. Names and agencies truncate rather than wrap. The selected row lifts to white with a burgundy spine; hover is a lighter wash. No blue.
  6. Nothing above a card body scrolls. The page itself never scrolls at any height — the masthead, the hero and both card headers are fixed rows, and the only scrollers are the query list and, when the viewport is short, a card body. Drag through the four heights: at 900 and 1080 everything fits outright; at 768 the type and padding tighten and Tracking's timeline takes an internal scroll; at 700 the nudge event drops out of the timeline rather than the card growing a scrollbar for one line.
  7. The stack fills its column. Notes takes the remaining height with its list scrolling internally and the composer pinned at its foot, so neither right-hand card trails off into white. Tracking's progress bar moves inside the Waiting event, where it belongs — it was floating as a separate box beneath a timeline that had already ended.
