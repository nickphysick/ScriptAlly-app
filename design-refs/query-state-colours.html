Query state colours

The band answers one question — whose court is it in — with three tints plus one for Offer. Time pressure is a chip laid over the band, not a fifth colour, so "overdue" never gets a hue of its own that could read as a verdict.

If you decide the chip is too quiet for the agent-overdue case, the escalation is to deepen the same band one step (pink → #eccbbf / #e6bfb1) rather than introduce a new hue. Same state, louder — never a different meaning.

Where it applies

Same four tokens drive the panel header band, the selected-row tint in any list view, the dashboard pipeline cells, and Fortnight in Focus — one vocabulary app-wide. They go in design-refs/themes.md as --turn-you, --turn-agent, --turn-offer, --turn-closed (each a pair, start/end) with Bold Pastille and Editorial values filled in when those themes are next touched.
