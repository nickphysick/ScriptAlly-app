THE RULES BEHIND THIS PAGE

  • Editions. Changing what's in a package starts a new edition. Renaming it, or changing which one is "used for new queries", doesn't.
  • Sent versions are locked. Once query letter v3 has gone out, editing it makes v4. The words in v3 never change.
  • Retire, don't delete. A package that's been sent can only be retired. It leaves the choices but keeps its results. One that was never sent can be deleted.
  • Fair rates. "1 in 3 answered" counts only queries with an answer (a request, a pass, an offer or closed as no reply). Queries still out are shown separately.
  • Sent with changes (based on the package, then altered) are listed, but not counted in its results.
  • No colour-coded chart: six plain numbers read faster and survive every screen.

WHY IT'S SAFE

  • Credit is worked out from the query, never stored on each entry. Correct the query's package, and every result moves with it.
