Recommendation: A. It's the pattern the best glance cards share — colour once at the top to say what kind of thing this is, then plain paper — and here the colour is already meaningful, because it's the Query Centre's ladder. A writer who has learned that pink means "the ball came to you" reads this card's header the same way without being told. It uses the app's own card chassis (edge, rim, shadow), so it looks like a Query Centre card that has been picked up and set beside the sheet — which is exactly what it is.

B if you'd rather the card stayed quieter — the edge is the smallest honest use of the tint. C if you want the agent to feel like the subject; I'd resist it here because the reference is about the query, and the agent is one fact of it.

Two rules that come with A: the header is the only tinted region on the card, and its colour is derived from status through the same function the Query Centre uses — nothing stores a colour. And the header's second line always says how long ("since 2 April · 22 weeks"), because that is the single fact a writer opening a task most wants without asking.
