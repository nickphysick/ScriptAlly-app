The desk, as built

⌕ Search

Turns the line into a search box. It matches the task, the agent and the agency. ✕ or Esc closes it and brings the tabs back.

☰ Filter and group

One menu. "Show only" narrows by task type or when it's due, and a small rust dot stays on the icon while a filter is on, with a line above the list saying what's showing. "Group by" changes how the list is grouped.

« Collapse

Shrinks the list to a thin strip of coloured counts, one per group, so the desk gets the full width. Click the strip to open it again. The app remembers which way you left it.
