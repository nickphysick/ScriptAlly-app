The agent card, brought up to the query card

Your agent card with the eight changes in. Use the Card switch to compare it with the card as built. The tabs, the arrows, the Agent fit stars and the notes box all work. Press the pencil on the proposed card to edit, then try Save, Undo, Cancel and Discard. On Waiting, move the response time to see the offer to move the query’s dates.

What changes

  1. One height. The card is always full height, as the query card is. As built it shrinks to what’s in it.
  2. Headings you can read. Section headings are in the typewriter face at 17px, as on the query card’s Agent tab. The 10.5px spaced capitals go.
  3. One layout for an agent. Profile opens with the three fact boxes and the contact buttons, then what they ask for, their wishlist and genres. It’s the query card’s Agent tab with more in it.
  4. Gaps in one place. Missing details sit in one “Finish this profile” block. A section with nothing in it isn’t drawn, so a new agent isn’t a column of grey bars.
  5. Colour from the query. The band stays slate on every agent. The disc ring, the status pill and the query box take the stage colour of the live query.
  6. A footer that does something. Where it stands and the one button move to the footer. The arrows move up to the band and “Added” moves to the end of Profile.
  7. History as a conversation. History is the query card’s thread, with “x days later” at the side. Notes gets the fixed writing box and the agent’s own words.
  8. Saving and moving on. The card straightens while you edit. On Save it leans back and bumps once, with the query card’s own bump, what changed holds a tint for a moment, and a line confirms it with Undo. Cancel and Discard lean back with no bump. The query box opens the query card, whose Agent tab links back here.
