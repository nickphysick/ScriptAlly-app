4 · THE BEST-IN-CLASS FEATURE REGISTER — researched against Sunsama, Linear, Things, Trello, Notion and the 2026 pattern literature; each marked HAVE / ADD / SKIP with the reason. The skips are as deliberate as the adds.
Saved custom views SKIP FOR NOW

Linear/Notion let users save filter+sort combos as named views. Your FILTERS + tags cover the need at this scale; revisit if power users ask.

Priority keystrokes SKIP

Sunsama sets priority with a single key. Your priority is derived (the engine ranks), so a manual priority would fight the bench. Deliberate absence.

Time estimates on Today ADD LATER

Sunsama’s defining move: tasks carry estimates and the plan sums them (“est. 45 min”), which keeps a day honest. Fits your Today header line; a later pack.

Carry-over review HAVE

Sunsama’s morning ritual reviews yesterday’s leftovers. Your roll-forward + “rolled forward” markers + the weekly briefing are the calm version.

Hyperfocus mode HAVE

Their one-task fullscreen is your dock walking the queue — same job, already unified with Work the list.

Collapsible columns ADD

Trello/GitHub let a column fold to a slim rail (name + count, rotated). Cheap, and useful when Snoozed/Done are noise during triage. One session.

Column sort override SKIP

Per-column manual ordering means stored positions — the exact state class the board was rebuilt to avoid. The global sort control is the answer.

Multi-select on the board ADD LATER

Shift-click cards → the batch bar (already designed for the list). Wire the same selection model to cards when batch ships.

Density toggle SKIP

Linear offers compact/comfortable. One well-judged density beats a setting; your cards are already the compact end of Trello’s.

Sync/offline indicator HAVE

ALL CHANGES SAVED in the top bar is the shell’s; the save machine feeds it. Nothing more needed.

Progressive disclosure HAVE

The 2026 trend the whole board already obeys: folds, benches, sweeps-as-one-card, the dock revealing flows only when summoned.

Illustration system ADD — SLOTS SPECCED

Five art slots: DONE-EMPTY · DESK-CLEAR (the hero) · DOCK-DONE stamp · NOTEBOARD-EMPTY · REVIEW-MASTHEAD. Fixed-ratio placeholder component now; the illustrator’s work drops in without layout shift.
