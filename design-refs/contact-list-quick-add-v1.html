Every empty cell is a dashed slot — the same idiom as the ghosted material slots — and every slot opens the same small editor anchored to it. Type, press Enter to save, Tab to save and jump to the next gap in the row, Esc to abandon. The cards below are the same records — watch them fill in as you type, because there is only one store and the popover writes to it through the same path the drawer uses.
