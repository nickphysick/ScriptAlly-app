What changes

  • The moment someone is most likely to feel let down, so it gets a warm, plain email.
  • Says exactly what happens if a place frees up, and that they needn’t do anything.
  • No promises beyond what the system does: an unsubscribe frees a place for the next in line.
  • The pass stub reads “Waiting list” instead of a number, so it still feels like part of the same set.

Notes for the build

  • Email clients don’t load web fonts reliably: the typewriter headings fall back to Courier, the serif to Georgia, and the handwritten “Nick” to a cursive fallback. Outlook ignores rounded corners. The emails stay readable either way.
  • Images in emails need to be PNG, not WebP (Outlook and some Gmail views don’t show WebP), and hosted on queryhawk.net.
  • The pass number in the welcome email is the writer’s stored founding number, as today.
  • When the places are gone, the ticket stub shows no number (the build already does this: no number when the cap is reached or the count hasn’t loaded).
  • Check before building: the page and this email both say you’ll email them if a place opens. Make sure something actually sends that email when a founding writer unsubscribes, or soften both lines.
  • The waiting-list email needs a new send in the confirm handler for the “waiting” outcome; the page already handles that case.
