One surface, three contents. White panel, the same shadow the filter and sort panels use, hairline rim, anchored to the pill or button that opened it with a 6px offset — useFixedMenu like everything else, flipping and constraining the same way.

Functionality:
  • The Attach menu lists the full set of four; attached types stay listed but inert, so the menu is where you learn what a send can carry. Synopsis and Query letter attach on click and the menu closes — nothing to configure. Opening sample attaches and hands straight over to its editor, because a sample without a size is half a fact; the → SIZE hint says that before you click. Other opens with the free-text field focused.
  • The editor: stepper with a typeable value, unit pills, and the agent's stated preference as a hint line — Foxglove ask for the first three chapters — so the writer can match it without leaving the popover. That line renders only when the agent record has a preference.
  • Every change commits immediately. There is no Done and no Save: click away or Esc to close, exactly as the filter and sort panels behave. The old black Done pill existed because the sheet didn't commit as you went; once it does, the button has no job.
  • Remove from this send sits at the foot of both editors: closes the popover, the pill disappears, the undo toast appears. One removal path whether you start from the × on hover or from inside the editor.
  • Keyboard: arrows move the menu, Enter chooses, Esc closes and returns focus to the pill; the stepper takes typed digits and arrow keys.
