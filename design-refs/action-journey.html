The rules that make it one journey

  1. One component. The Action sheet is a single modal, owned by one module, opened by every entry point with the same call: openAction(kind, relationshipOrTask, prefill). No page has its own version.
  2. Four kinds, one shape. Nudge · Sent materials · Response · (Task tick, sheetless unless linked). Each sheet is: what happened → when → the one fact the app needs next (a date, a reply window) → an optional note → "What this does" → one primary button.
  3. "What this does" is always shown before committing: the status change, the task it completes, the reminder it sets, the bar it creates. Written in the same words the pages will show afterwards.
  4. Same vocabulary everywhere. Statuses are QC's nine; holders are With you / With the agent / Offer; lateness is one form. The sheet, the toast, the card header and the calendar band all say the same thing.
  5. One outcome, all surfaces. A single write to the relationship's activity produces the QC card, the To-do row, the Calendar bar and the At-a-glance counts. Nothing is written per page.
  6. Undo, not confirm. No "are you sure?"; every commit shows an 8-second toast with Undo, and Undo reverts the whole write (status, task, reminder).
  7. Dates default to today, with Yesterday and a picker one tap away; agency reply windows default to the usual (editable) so no one is forced to invent a date.
  8. Linked tasks record; plain tasks tick. A tick on a relationship task opens its sheet pre-filled; a plain task just completes.
  9. Entry never changes the journey. Whether you began on a card button, a row tick, a bar's hover action or the drawer's primary action, step 1 is the same sheet with the same prefill.
