Rules this sweep adds — beyond what the cards show:

The root is the earliest event, not the "Query sent" event. Imported queries can begin at Partial Sent with no request before it — the guard must protect by position, or an import's foundation is deletable while a normal query's is not. ⚠️ CC must confirm what imports actually produce as their first event.

Kind edits stay within direction. A request can become another kind of request, a send another kind of send — an event can never cross from incoming to outgoing by editing, because that is not a correction, it is a different fact. Card 9's paired-edit nudge exists because a misread email usually poisons both halves of the round.

Ordinal headings renumber themselves. Delete the first partial round and "The second partial" becomes "The partial" — free, because the labels derive, but the preview should show it so the writer isn't surprised.

The preview computes on change, not on keystroke. A date field mid-typing reads "2" of "22 August" — running the engine on every character flashes nonsense consequences. Compute on blur or completed change.

The ⋯ affordance mounts in the Query Centre only. TimelineRows also serves the To-do focus sheet — the correction menu is a prop, off by default, so FocusFlow is untouched.

And the undo contract, stated once: restores by id; names event and query; survives selection changes; retired by any newer write to the same query; always one toast per operation however many documents moved.
