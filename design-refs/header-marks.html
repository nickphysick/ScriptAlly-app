How this is built
  • The mark sits in a fixed 28px box with its own faint parchment plate. Icon now, illustration later — the box never changes size, so swapping one for the other moves nothing. Toggle above to prove it.
  • Assets render object-fit:contain inside the box, bounded at the declared dimension. The placeholder states the slot name in mono, per the ArtSlot convention.
  • Each slot's brief lives in a code comment beside it, not in the rendered markup — e.g. Activity is "a clock face over a stack of filed cards".
  • Icons are monoline, 1.5 stroke, burgundy — consistent with the icons-for-state rule. When illustrated marks replace them the rule flips the other way, which is the intended destination: these headers label surfaces, not controls.
  • The rim is inset 0 0 0 1px, never a border, and hover is shadow-only — no transform, no scale. That's the fix from 65-hover-rim.html applied as the container default.
  • The plate behind the mark is rgba(253,250,245,.72) so it reads on both the sage band and the pink To-do band without a second rule.
