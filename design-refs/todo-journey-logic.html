The logic of each journey

The rule applied throughout: a journey starts with the decision, not the paperwork. The first thing the pane asks is what the writer wants to do — and each intent gets its own short ledger, its own primary verb, and where it belongs, a crossover into a neighbouring journey (closing and nudging are each other's second thoughts). The quantity pill is also corrected here: choosing a unit opens the picker with the value focused and selected — type to replace, or nudge — it never silently accepts a default.
