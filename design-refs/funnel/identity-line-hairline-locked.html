What to bake

  • Rule: 1px × 15px, #dbcfc0, margin: 0 11px, a flex child with flex: 0 0 auto — never a border on the name, which would move with its text.
  • Identity line is display:flex; align-items:center; min-width:0. Name is flex: 0 0 auto; agency takes the remainder and truncates with an ellipsis rather than wrapping.
  • The rule renders only when both a name and an agency exist. One value alone occupies the Playfair slot at full weight — no rule, no placeholder.
  • Agency is Playfair roman 15px in --muted, not italic.
  • Same component serves both stages, so agentPrimary / agentAgencyLine decide which values are present rather than the row doing its own checks.
