1 · Cross-highlighting. Hovering a chip dims every ledger row that doesn't use it; hovering a cell lights its chip. "Where is this used?" and "what is this made of?" answered by looking, with no click and no extra surface.
2 · The build row is closed until wanted. A permanent empty three-slot form made the page look unfinished. It is now one quiet line that opens on click — or arms itself the moment you start dragging, so drag never has to find a hidden target.
3 · The name suggests itself. Fill two slots and the field proposes Hook-first · Prologue-first — editable, never forced, and it disappears if you type over it. Naming is the friction in building a package; this removes it without deciding for you.
4 · Duplicate combinations are stated, not blocked. Assemble a set that already exists and the footer says which package it is. You may still create it — that is a legitimate thing to do — but you will not do it by accident.
5 · Sortable counts, with a scale bar. A hairline bar under each number shows it against the column's largest, so ten packages compare at a glance rather than by reading. Click a count head to sort.
6 · Unused materials are marked. A letter or version in no package carries a quiet NOT USED tag — a fact, not a nudge, and the answer to "what have I written and never tested?"
7 · Row actions on hover. DUPLICATE & EDIT appears on the row rather than living in a menu, so the escape hatch from a locked package is where the locked package is.
Everything is keyboard-reachable: chips are focusable and fill the next empty slot on Enter, the build row opens with Enter, and slots clear with Delete. Drag is an accelerant, never the only route.
