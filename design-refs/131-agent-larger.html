Bare icons, agent larger
The manuscript title holds at 21px and the agent name steps up above it. That is the right way round for this card: the row you clicked in the list was an agent, so the agent is what the card should confirm first — and the manuscript is the constant, since it is the same book on every query in this view.

Try the four sizes against the second card. Penhallow Literary with Agent not specified is the longest name in the set and the one where a large size starts crowding the status block. 24 and 26 both hold; 28 is where the line begins to feel like a page title rather than a card heading — which matters, because the masthead above already claims that role.

What the size difference is doing is what the mono labels were doing badly: it tells you which line is the subject without spending a word on it. The icons then only have to say which kind of thing, which is a job a 20px glyph does well and a word does redundantly.

Bare icons keep the card flat, so the only circular element on it remains the status mark — the eye goes name, then status, which is the order you actually read in.
