Getting in — redesign v1

What's wrong with getting in today

Read from the dev line (the build dev serves), not main.

The founder's code

  1. The gate is built but not switched on. The redeem function isn't deployed and no codes exist, so today anyone with the address can create an account, and nothing marks a writer as founding.
  2. The writer has to type the code. It sits as the first field of a five-field form, with a placeholder that still starts "SA-" from ScriptAlly.
  3. The email calls it one thing and the form another: "founder's code" in the offer, "invite code" on the page.
  4. Their pass isn't there. You already have a numbered pass drawn for every founding writer ("No. 12 of 50, Confirmed") and it's only used in the email. The sign-up page shows a generic panel.

The forms

  1. Labels are tiny mono capitals ("EMAIL ADDRESS", "YOUR INVITE CODE"), under the 12px floor and in the eyebrow style you've ruled out. Fields are dashed underlines with typewriter placeholders, unlike every other input in the app.
  2. Everything at once. Code, Google, name, email and password on one screen, when the email address is already known from the invite.
  3. Errors aren't designed. Wrong password, "this account uses Google", a used code and an expired link each need their own plain sentence and a way forward.
  4. The same flock drawing appears on create, sign in and reset.

Dead ends

  1. An unknown address silently drops you on the Dashboard. A mistyped or out-of-date link looks like the app ignoring you.
  2. The crash card is in the old fonts with a burgundy outline button, no drawing, and no way to tell you what happened, though the feedback route is one click away.
  3. Signed out and following a link: worth confirming the app returns you to that page after sign-in; I couldn't see it doing so.

Your notes (checked, not redesigned)

  1. Built on dev and in good shape. It already sits in the rail and shows the rank that Settings links to.
  2. One fix: the "Now in the app" chip is green. QueryHawk never uses green.
  3. One question: its big "6 notes sent" title is in the book face; the Query Centre title moved to the typewriter face on 9 Nov. They should match.
