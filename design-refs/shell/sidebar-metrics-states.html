The sidebar, measured

Width, line spacing and type, checked against the apps that do sidebars best — then every interaction state and its timing, written down. The “Tuned” sidebar below is live: hover the rows, open the New button, Tab through it for the focus rings.

WHAT CHANGED, AND WHY

  • rows: padding 6px 10px (~29px)32px fixed height, flex-centred, padding 0 10px. Every row the same height whatever wraps inside it, and a bigger target. height:32px · gap 2px (was 1)
  • eyebrows: margin 16px 8px 5px20px above, 6px below. The groups breathe; the hairline keeps doing the separating so the gaps don’t have to be huge. first group sits 22px under the New button
  • nav 14.5px · labels 8.5pxUnchanged — deliberately. 14.5px Source Serif 4 reads like a 13.5px sans, inside the Linear–Notion band. The 8.5px mono eyebrow is the house label everywhere else; the sidebar shouldn’t fork it.
  • no capture controlThe split button, 36px. Taller than any row, white against stone — the only raised, lit surface, so the eye lands on the verb. Main segment “Log a query”, 14px/600; chevron 32px for a square hit. radius 10 · hairline inset + 1px 2px shadow
  • Dashboard above the first ruleEvery row sits under an eyebrow once the button takes the top slot — Dashboard gets WORKSPACE, so the rhythm is button, then ruled groups all the way down.
  • width 248 / 68 collapsedUnchanged. “Submission packages” plus icon and count needs ~210px of text room; 248 gives it air without Slack-level sprawl.

Motion, in one table

The grammar: hovers are plain ease and asymmetric (fast in, gentler out); anything that opens uses the house ease and travels at most 4–6px; closing is always faster than opening; navigation never animates. Under reduced motion, every duration is 0.

The 68px rail

Collapsed, the button keeps its rank: a white 40×36 tile with the quill — still the only lit surface. The menu becomes a flyout on the rail’s right edge, and the main action moves inside it as the first row, so nothing is lost. Hover the quill tile to see it.

Q

Keyboard, in full. The chevron opens on Enter / Space / ↓ with focus on the first row; ↑ ↓ move and wrap; Enter picks; Escape closes and returns focus to the chevron; Tab closes without trapping; a pointer press outside closes. The main segment is a plain button — it just logs a query.

No shortcut hints yet. The menu shows no keycaps and nothing binds a key, until the shortcuts registry from the switcher pass exists. Once it does, “N → open the New menu” is one registry entry away and the sheet picks it up for free.

Tooltips on the rail name every tile, the New button included, after the 400ms delay. The flyout and the tooltip never show together.

Reduced motion zeroes every duration in the table — the chevron still flips, the menu still appears, nothing travels.
