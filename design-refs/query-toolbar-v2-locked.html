Toolbar popovers · Group · list headers

Three fixes: the dropdowns get the app's own chassis and a much shorter menu; Group is specified so it visibly does something; and four options for the list header.

1 · Popovers — MountCard chassis, short menus

Same three-layer chassis as every panel in the app: parchment rim, inset burgundy hairline frame, sage band header. Options are 13px Inter with a rounded hover, pink when active, counts in mono on the right. Filter keeps two facets only — Status and Sent via — with an "Included" facet dropped (it was a fifth way to ask a question nobody asks in a list). Sort keeps five, with direction as a segmented control in the footer rather than five more rows.

2 · What Group must actually do

Group is currently inert. It should partition whichever view is showing, keeping Filter and Sort applied within each group:
Grid — a Playfair 17px section heading with a count pill and a rule in the group's accent colour, then that group's cards; groups in ladder order for Status and Whose court, newest-first for Month, A–Z for Agency.
List — the same heading as a full-width row between the rows of each group (shown below).
Board — Group is disabled with the button reading `Group Status` and a tooltip "The board is already grouped by status"; choosing another value switches the board's columns (Whose court → four columns; Agency → a column per agency; Month → a column per month).
Calendar — groups become lane sections.
Empty groups are omitted. The heading row is not sticky.
