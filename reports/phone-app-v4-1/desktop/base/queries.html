A note on these numbers

Everything on this page comes from what you have logged. Three things worth keeping in mind when you read it.

Small numbers move a lot. With 10 replies, one more reply shifts the figures noticeably. Treat them as a rough picture, not a precise measure.

No reply is not a no. The 4 queries still waiting count in the rates as not yet asked to read more, so the rates can go up or down from here.

The page cannot see inside an agency. How full an agent’s list is, whether they are on leave, or when they actually read your letter all affect these numbers, and none of it is recorded here.

iPackage guidelines
  • Every package goes Draft → Ready → Out with agents. Draft until it has a letter and pages; Ready to pick when you log a query; locked once the first query goes out, so its results stay true.
  • Want to change one that’s out? Make a new package from it. The original stays exactly as agents got it.
  • Change one thing at a time. If two packages differ only by the letter, Results can tell you which letter does better.
  • Give it five queries before judging. One or two replies can swing a percentage either way.
  • Name it for who it’s for, like “Standard UK” or “US agents”, so it’s easy to pick when you log a query.
  • Fixing a typo? Edit the letter itself. A small fix keeps the same letter; a rewrite is a new letter.

As writers join, their agent lists build one shared catalogue. Every agent in it is checked by hand before the Scout brings you the ones who want a book like Murphy's Day Out — with the reasons they fit. Nothing joins your contact list without you.

How it works.

  1. Illustrationa writer adding an agent card to a growing pile
    1

    Writers add the agents they’re querying.

    Every contact list on QueryHawk feeds one shared catalogue. Yours already has — nothing more to do.

  2. Illustrationthe Archivist with a stamp, checking a card
    2

    Each agent is checked by hand.

    A real agency, open to queries, never a reading fee. An agent only reaches the Scout once it’s been verified.

  3. Illustrationthe Scout with binoculars, holding out a card
    3

    The Scout brings you the ones that fit.

    A few at a time, matched to your manuscript’s genre and the agent’s wish list, each with the reason. You decide who joins your list.

The Scout never writes to an agent for you. It finds them; querying is still yours.
